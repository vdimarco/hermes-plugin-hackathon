Three plugins for [Hermes Agent](https://github.com/NousResearch/hermes-agent) that make an agent's "done" something you can check. Built for the Hermes Agent Plugin Hackathon.

| Plugin | What it does |
|---|---|
| [**Vouch**](https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/vouch) | Checks every claim of finished work in the agent's reply ("tests pass", "pushed", "deployed") against what the agent really ran. A false claim sends the agent back. |
| [**Contract**](https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/contract) | You approve the definition of done before work starts. The agent cannot edit the locked tests or finish while a check fails, and it ships a receipt that anyone can re-run. |
| [**Multiverse**](https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/multiverse) | Races 2 to 6 attempts in separate git worktrees, judges them with the same checks, and applies the winner. It can race models too. |

## New in 1.1.0

- **Hermes Desktop halves** for all three plugins (`desktop/plugin.js`):
  - Vouch: a status-bar chip with the verdicts on the latest reply.
  - Contract: a live checklist pane, a chip, a toast when the lock blocks an edit, and a command that copies the receipt hash.
  - Multiverse: a live race board, a chip while racing, and a toast that names the winner.
- The Python side pushes state with `broadcast_plugin_event`; the desktop side only listens.
- Catalog card images, and an install section with Hermes Desktop links in each README.

## Install

```bash
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/vouch
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/contract
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/multiverse
hermes plugins enable vouch contract multiverse
```

Then turn on the Desktop halves in **Capabilities → Plugins**.

## Safety

None of the plugins make network calls or hold credentials. Contract and Multiverse run shell commands only through the Hermes terminal tool, so your approvals and terminal backend apply. Each README has the full disclosure.

## Tested

Unit tests per plugin, suite rules (no shell, network or core overrides; Hermes' desktop admission lint), Node tests for the desktop halves, and integration tests that run the real git commands in a temporary repository. CI runs on Python 3.11 to 3.13 with Node 22.
