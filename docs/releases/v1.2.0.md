Vouch now ships inside [Contract](https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/contract). One install gives you both: a definition of done that the agent cannot fake, and a check on every claim of finished work in its reply.

## Changed

- **One plugin, one tool record, one footer.** Contract records every tool call once. The contract gate and Vouch, the claim check, both read that record. Hermes keeps only the first plugin rewrite of a reply, so Contract writes one footer: the claims Vouch could not verify, then the contract's status line.
- **Order at the end of a turn.** The contract gate runs first. When it lets the turn end, Vouch checks the draft reply and sends the agent back once if a claim is false.
- **Settings.** The claim check uses `claims_mode` (nudge, annotate, off), `claims_max_nudges`, `claims_footer_verified` and `claims_kinds` under `plugins.entries.contract.settings`. `footer` covers both parts.
- **Hermes Desktop.** The Contract half now also shows the Vouch chip and the "sent back" toast. The Python side sends `plugin.contract.report` events.
- Multiverse: version number only.

## Removed

- The separate `vouch` plugin. If you installed it, remove it and install Contract:

```bash
hermes plugins disable vouch
hermes plugins remove vouch
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/contract
hermes plugins enable contract
```

## Verified

- `hermes plugins validate` and `hermes plugins doctor` pass for Contract and Multiverse against the current Hermes source.
- `scripts/smoke-hermes.py` drives both plugins through a real Hermes install, with no LLM needed. All 25 checks pass.
- Unit, Node and integration tests pass on Python 3.11 to 3.13.

## Install

```bash
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/contract
hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/multiverse
hermes plugins enable contract
hermes plugins enable multiverse
```

Then turn on the Desktop halves in **Capabilities → Plugins**.
