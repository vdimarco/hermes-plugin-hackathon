A fix release for [Vouch, Contract and Multiverse](https://github.com/vdimarco/hermes-plugin-hackathon), found by running all three inside a real Hermes install.

## Fixed

- **Vouch and Contract now share one reply footer.** Hermes keeps only the first plugin rewrite of a reply, so with both plugins enabled, Contract's status line hid Vouch's footer. Now Contract yields while Vouch is enabled, and Vouch's footer carries Contract's line (proposed, 2/3 checks pass, or met with the receipt id). Vouch reads that line through Contract's `contract_status` tool. Contract alone behaves as before.
- **Install docs:** `hermes plugins enable` takes one plugin name, so the docs now enable the three plugins in a loop.

## Added

- `scripts/smoke-hermes.py`: a smoke test that drives all three plugins through a real Hermes install, with no LLM needed. It runs Hermes' own tool path (`handle_function_call`), plugin hooks and slash commands, real terminal commands and real git worktrees. All 23 checks pass.
- `contract_status` now also reports the summary and the receipt hash.

## Verified

- `hermes plugins validate` and `hermes plugins doctor` pass for all three plugins against the current Hermes source: manifest, capability match, security scan, no core override, desktop surface.
- Unit, Node and integration tests pass on Python 3.11 to 3.13.

## Install

```bash
for p in vouch contract multiverse; do
  hermes plugins install https://github.com/vdimarco/hermes-plugin-hackathon/tree/main/plugins/$p
  hermes plugins enable $p
done
```

Then turn on the Desktop halves in **Capabilities → Plugins**.
